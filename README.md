# ChatGPT Prototype

Interactive prototype of a compose and answer feature for the ChatGPT iOS app (speculative design, UX/UI student project).

Single self-contained `index.html`: all CSS, JavaScript, icons and the Inter font are inlined, so there are no external requests.

- **Phone:** shows full-bleed with no frame.
- **Desktop:** shows inside a phone frame, scaled to fit the window.

## Publish with GitHub Pages
1. Create a repository and upload these files to the root of the default branch.
2. Settings → Pages → Build and deployment → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`.
3. Open the address GitHub shows (`https://<user>.github.io/<repo>/`).
